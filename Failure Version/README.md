# 字有引力

面向 5—8 岁儿童的黏土风汉字冒险 MVP。写“木”、拼“林”、用“雨”，再选择桥、船或童话大鸟帮助狐狸过河，最后在花园中再次使用“雨”。

## 本地启动

需要 Node.js 20.19+ 或 22.12+（当前验证环境：Node.js 24）。在本目录执行：

```powershell
npm install
npm run dev
```

打开 http://127.0.0.1:5188 。前端运行于 5188，Express 运行于 3018，Vite 代理 `/api`。默认只监听本机。开发服务未配置 AI 时，基础玩法仍然完整可玩。

## 接入真实 AI

```powershell
Copy-Item .env.example .env
```

在本地 `.env` 填入 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY`，然后重启 `npm run dev`。地址填写兼容服务的 API 根地址（例如以 `/v1` 结尾），程序会追加 `/chat/completions`。密钥仅由 Express 读取，不使用 `VITE_` 前缀，不写入前端或提交到仓库。

过河关卡点击“我有一个不一样的办法”，输入自由表达。AI 只能建议桥、船、鸟，孩子确认汉字后仍要亲手放置。服务端验证输出结构，7.5 秒中止模型请求；前端 8 秒回退。连接状态在“设置”中显示，只有真实请求成功后才显示“AI 已成功响应”。

当前没有配置模型凭据，因此未进行真实供应商联调；已验证兼容协议的模拟响应解析、未知行动拒绝及未配置时的 HTTP 回退。模拟测试不会在产品内伪装成真实 AI。

## 构建与验证

```powershell
npm run build
npm test
npm start
```

生产构建后 Express 同时服务前端与 API，打开 http://127.0.0.1:3018 。`npm test` 检查三种路线、任务顺序、存档损坏、描摹方向及路径覆盖、AI 结构和字块映射。

可重复的端到端脚本（先保持开发服务运行）：

```powershell
npm run test:browser
```

默认使用已安装的 Microsoft Edge，在独立临时上下文中检查 1280、390、360px 布局及三条路线。可用 `BROWSER_CHANNEL=chrome` 改用 Chrome；脚本将截图放入 `test-output`。本次已通过浏览器工具进行实际操作验收；此可选脚本用于后续回归。

## 素材与边界

- `public/assets`：本项目生成的原创黏土小岛和透明狐狸素材；用户的参考图未作为运行素材使用。
- `public/audio`：固定普通话任务提示、拼字反馈和六个字的读音及释义，构建时已提供，运行时不请求音频生成服务。动态 AI 回复使用设备可用的中文语音；没有可用语音时保留文字。
- `public/fonts`：本地 Noto Serif SC 字体子集，附 SIL Open Font License。界面使用系统中文字体；汉字使用清晰的宋体字形。首版未引入另需确认授权的楷体文件。
- 固定音频可通过 `node scripts/generate-audio.mjs` 重新制作；该开发脚本需联网使用 Edge Read Aloud，游戏运行不依赖它。字体生成脚本为 `node scripts/local-font.mjs`。
- 场景底图负责黏土材质，SVG 与 CSS 负责树冠、河水、工具、角色位移和花园反馈，所有教学汉字由前端绘制。
- 浏览器仅保存版本、稳定任务进度、使用过的字、过河路线、声音偏好和尝试次数；不保存自由表达正文。清空浏览器数据会丢失进度。
- 描摹为横、竖、撇、捺的路径引导，不是自由手写识别或书法评分。汉字手册的“探索过”不代表已经掌握。
- “离线基础玩法”指不依赖外部 AI 网络；应用文件仍需由本地或静态服务器提供，未实现 PWA 安装和首次离线加载。
- 尚未开展儿童试用，也不声称已验证学习效果。

## 三分钟演示

1. 写下“木”，让枯树长出树冠。
2. 点两次“木”并把“林”放进小岛。
3. 把“雨”放进天空，河水恢复。
4. 输入“我想让狐狸飞过去”等想法（需先配置 AI），确认推荐字块并亲手使用。
5. 在花园中再次使用“雨”；展示不同办法带来的不同过河动画。
