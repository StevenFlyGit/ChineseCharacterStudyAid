# 六字楷体书写流程

木、林、雨、桥、船、鸟共用黏土书写面板。首次选择先演示笔顺，再逐笔描摹；完成后点击“获得字卡”，才将该字记入 LocalStorage 的 written 字段。以后选择已写过的字直接使用，并提供“再写一次”。未写完关闭不会记录完成，拖放和 AI 建议也遵循首次书写限制。

## 数据与实现

使用项目内 npm 依赖 hanzi-writer 3.7.3 与 hanzi-writer-data 2.0.1。只导入六个字的 JSON 到前端构建，包含楷体笔画轮廓和逐笔中线，不需要运行时请求字库 CDN。字卡与临摹区采用同一组轮廓；不是将普通字体机械放大。笔顺演示、描摹判断由 Hanzi Writer 完成，起笔圆点、方向箭头及笔画名称由界面呈现。

汉字数据来自 Make Me A Hanzi 的 Arphic 楷体轮廓。字体风格及笔顺应在扩大到教学产品前逐字做教育内容复核，不宣称国家教材认证。官方资料：[Hanzi Writer 文档](https://hanziwriter.org/docs.html)、[字库来源](https://github.com/chanind/hanzi-writer-data)。许可证随构建保存在 public/licenses。

## 移动端

描摹区响应容器尺寸变化；使用 Pointer Events 支持鼠标、触屏与手写笔，书写时禁止画板内滚动。关闭后清理监听器。手机采用纵向布局，按钮至少 44px 高；短屏面板可纵向滚动。
