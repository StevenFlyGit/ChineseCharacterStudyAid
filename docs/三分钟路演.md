# 心音字灵 · 三分钟路演
## 0:00—0:30 问题与定位
“面对复杂的汉字，有些孩子不知道从哪里开始。我们希望给确诊读写障碍的孩子一个由家长或教师陪伴的识字空间：不催促，一块一块看。”
“我们选用‘赢’展示复杂字如何被组织成可理解的小块。这是教学联想原型，目前尚未验证学习效果。”

## 0:30—1:30 操作高光
点击首页“一分钟路演”。开场约7秒，结构聚焦约5秒，五句故事约20秒：
“亡像小帽，口来呼唤，月亮照路，贝壳作伴。平凡的我，一步一步向前。”
此处是记忆联想，不是字源解释。
故事结束后依次点选五块，再点对应的编号位置：亡在最上，口在其下，月在下左，贝在下中，凡在下右。
可故意放错一次：“系统会提示位置，不打叉、不扣分。”
五块归位后出现完整‘赢’；再从三个无颜色提示的字中实际选出‘赢’。
说明：“结果来自刚才的操作，并非动画结束后直接宣布掌握。”

## 1:30—2:15 AI 与产品闭环
“我们固定经过核对的字形和知识，让 AI 只调整短讲解。默认本地故事，保证舞台演示稳定。”
打开设置显示来源。未配置真实 API 时只展示架构和回退，不能宣称刚才故事由实时 AI 生成。
配置并联调完成后可切换真实 API，请求新故事。超时三秒回到本地故事，显示实际来源。
说明低刺激、点选替代拖拽、静音可用、陪伴者记录以及刷新恢复。

## 2:15—3:00 后续验证与愿景
“接下来我们需要专业人员审阅：这些线索是否帮助记忆，还是增加了负担。”
“在有陪伴的试用中，我们会观察操作难度、无提示辨认以及延迟复习表现。一次成功不代表治愈或已经掌握。”
“之后按识字水平扩展更简单的字，再逐步延伸到词和短句。给每一种学习节奏，留一点空间。”

## 排练与备用
1. 演示前确认来源为本地脚本、声音可播放。清空测试进度，从首页开始。
2. 使用手机投屏或桌面居中的手机界面。暂停按钮可用于配合讲解。
3. 拼回与辨认必须实际操作；操作较慢时一分钟段落会延长。
4. 备份 docs/心音字灵-离线演示.html。它含固定音频、字形、UI与说明。
5. 路演不是儿童试用，不把自己的演示记录当作学习有效性证据。
