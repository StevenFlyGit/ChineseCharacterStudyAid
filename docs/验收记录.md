## 构建与自动验证
- TypeScript 严格检查及 Vite 生产构建通过。
- 7 项核心测试通过：17 笔分组完整、顺序及错误归位、辨认/求助记录、损坏存档、稳定恢复、AI 请求/响应校验及供应商协议适配。
- 浏览器使用独立 Microsoft Edge 上下文，全部场景通过：
  - 360、390、430px 手机触摸：完整流程、错误归位、刷新恢复、错误辨认、提示后辨认；默认无 API 请求，无横向溢出和页面脚本错误。
  - 1440px 桌面布局与固定普通话音频。
  - 实际本地接口未配置时返回并显示回退。
  - 受控 API 成功、无效 JSON、三秒超时，以及切回本地后旧响应不能覆盖状态。
  - Ctrl + H 切换故事模式。
  - 动画预览保留原学习记录，返回后恢复原阶段。
  - file:// 直接打开单文件 HTML，完成学习闭环，无外部 HTTP 请求和脚本错误。
  - 路演自动推进开场、聚焦、故事，暂停后时钟冻结，拼回和辨认等待真实操作。

- 16 段固定普通话音频（约 327KB），编入构建与离线 HTML。
- docs/心音字灵-离线演示.html：完整单文件演示。
- docs/三分钟路演.md：舞台讲稿、操作顺序和备用策略。
