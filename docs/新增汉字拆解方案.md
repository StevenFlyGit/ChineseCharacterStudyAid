# 镜、藏、警：拆解与故事方案（含四字辨认扩展）

状态：内容设计草案，未修改当前应用和线上站点。三个字都建议使用四块；复用“看清结构→听个故事→亲手拼回→再认一次”的流程，不固定五块。用户输入的是单字“镜”，而不是词语“镜子”。

## 共用交互

1. 结构页：按原字空间关系适度分开字块，直接点击高亮并播放名称和位置。没有下方编号条，不强制按序点完，重复点击可以重听。保留父结构关系，不把嵌套字块排成一排。
2. 故事页：每屏一句，当前字块与对应插画同时显示；完整故事约 15—25 秒。主要按钮仅负责下一句，最后进入拼回。
3. 拼回页：四块恢复原 SVG 坐标。选择字块，再点位置，错误保留选择并轻声提示。
4. 辨认页：去掉颜色和故事提示，默认在 6 个字中实际点选，可扩展到 9 个字（均包含正确答案）；不在动效结束时宣布已经掌握。
5. 减少动态、静音、暂停、重听和本机进度恢复沿用现有能力。手机点击区域至少 56px。

## 教学边界

结构分组固定。故事是记忆联想，不承担字源解释，不能暗示“镜框、宝盒、文字提示”是相应部件的真实字义。“藏”先采用 cáng 与隐藏场景；zàng、宝藏和西藏以后按具体词语另教。儿童不必先学会爿、臧的读音。

## 镜（jìng，16 笔）

基础结构：钅 + 竟。教学字块：钅 +（立 / 日 / 儿）。

布局：左边钅；右边从上到下是立、日、儿。

| 字块 | 点击后的位置提示 | 故事句 | 视觉联想 |
|---|---|---|---|
| 钅（金字旁） | 金字旁，在左边。 | 亮亮的镜框。 | 亮镜框 |
| 立（立） | 立，在右上方。 | 镜子立起来。 | 立起来 |
| 日（日） | 日，在右边中间。 | 太阳照过来。 | 太阳 |
| 儿（儿） | 儿，在右下方。 | 小朋友笑起来。 | 小朋友 |

完整故事：**亮亮的镜框，镜子立起来。太阳照过来，小朋友笑起来。**

拼回后释义：镜子能照出自己的样子。

辨认候选池：镜、境、竟、竞、锐、锦、景、静、惊。默认六字：镜、境、竟、竞、锐、锦。类型与差异见下方“四字候选池”。

重点：左侧金字旁与右侧“竟”区分；右侧日不能换成口，保留中间一横。

## 藏（cáng，17 笔）

基础结构：艹 + 臧。教学字块：艹 /（爿 + 臣 + 戈）。

布局：艹在最上；爿在下方左边；臣在下方里面；戈的原笔画围在外侧。

| 字块 | 点击后的位置提示 | 故事句 | 视觉联想 |
|---|---|---|---|
| 艹（草字头） | 草字头，在最上面。 | 草丛下。 | 草丛 |
| 爿（左边字块） | 左边字块，在下方左边。 | 小门旁。 | 小门 |
| 臣（里面字块） | 里面字块，在下方里面。 | 宝盒藏好了。 | 宝盒 |
| 戈（外侧字块） | 外侧字块，在下方外侧。 | 弯弯的围边护着它。 | 围边 |

完整故事：**草丛下，小门旁，宝盒藏好了，弯弯的围边护着它。**

拼回后释义：把东西放好，不让它露出来。

辨认候选池：藏、葬、茂、蔽、苍、仓、舱、脏、臧。默认六字：藏、葬、茂、苍、仓、舱。类型与差异见下方“四字候选池”。

重点：臣与外侧戈保留真实嵌套关系。戈的笔画并不连续，必须按 strokeIndices 收集，不能使用连续 slice。放置外侧字块时仍能看到里面字块的轮廓。草字头采用项目现有的三笔简体字形，不照搬四笔草头的地区字形。

## 警（jǐng，19 笔）

基础结构：敬 + 言。教学字块：（艹 / 句） + 攵 / 言。

布局：艹在左上；句在艹下面；攵在右上；言横跨下方。

| 字块 | 点击后的位置提示 | 故事句 | 视觉联想 |
|---|---|---|---|
| 艹（草字头） | 草字头，在左上方。 | 草地旁。 | 草地 |
| 句 | 句，在草字头的下面。 | 有一句话。 | 一句话 |
| 攵（反文旁） | 反文旁，在右上方。 | 写成文字： | 借与文的形状相似，联想文字 |
| 言 | 言，在下方。 | 过马路，慢慢走。 | 提示牌上的文字提醒 |

完整故事：**草地旁，有一句话，写成文字：“过马路，慢慢走。”**

故事画面：草地边有一块提示牌；讲到“言”时，牌上出现“过马路，慢慢走”。保留四个实际字块与画面的对应关系。

拼回后释义：提醒大家注意安全；警察的警。

辨认候选池：警、敬、誓、誉、惊、景、井、静、擎。默认六字：警、敬、誓、誉、景、井。类型与差异见下方“四字候选池”。

重点：攵保留为完整字块，儿童界面继续称为反文旁。它与文是不同字形，不能改名为文或替换 SVG 笔画；故事只借形状相似联想文字，需要时说明“它有点像文，我们借它记文字”。结构页只提示名称和位置，联想在故事页出现。句保留完整形状。当前项目简体字形的草头使用三笔。

## 再认一次：四字候选池

每课提供 **9 个候选字，含 1 个正确答案和 8 个干扰字**；首次默认使用 6 个（含答案），熟悉后可选择 9 个。形似、同音和近音可以重叠，但不能把读音不同的字标为同音。“藏”以本课 cáng 为准。

### 赢

默认 6 字：**赢、营、迎、盈、竟、竞**。完整 9 字：**赢、营、迎、盈、影、竟、竞、嬴、羸**。

| 候选字 | 类型 | 辨认差异 / 选取理由 |
|---|---|---|
| 赢 | 正确答案 | 保留亡、口和下方月、贝、凡的完整组合。 |
| 营 | 同音；部分形似 | 同读 yíng；都有上下排列和口形，但营有草字头，下方没有月、贝、凡。 |
| 迎 | 同音 | 同读 yíng；观察左下方的走之。 |
| 盈 | 同音 | 同读 yíng；下方是皿，字形较短。 |
| 影 | 近音 | yǐng，声调不同；右边有三撇。 |
| 竟 | 结构比较 | 上下结构，整体轮廓有部分相似；比赢短，下方是儿。并非同音字。 |
| 竞 | 结构比较 | 上下结构，整体轮廓有部分相似；下方是兄，没有月、贝、凡。并非同音字。 |
| 嬴（进阶） | 强形似；同音 | 同读 yíng；下方中间是女，赢的对应位置是贝。 |
| 羸（进阶） | 强形似 | 读 léi；下方中间是羊，赢的对应位置是贝。 |

### 镜

默认 6 字：**镜、境、竟、竞、锐、锦**。完整 9 字：**镜、境、竟、竞、锐、锦、景、静、惊**。

| 候选字 | 类型 | 辨认差异 / 选取理由 |
|---|---|---|
| 镜 | 正确答案 | 左侧钅，右侧竟；右侧中间是日。 |
| 境 | 强形似；同音 | 同读 jìng；右侧同为竟，左侧土与钅不同。 |
| 竟 | 形似；同音 | 同读 jìng；保留镜的右侧，但没有左侧钅。 |
| 竞 | 形似；同音 | 同读 jìng；没有钅，中间是口而非日。 |
| 锐 | 形似 | 同有钅，下方也有儿；右侧是兑而非竟，读 ruì。 |
| 锦 | 形似 | 同有钅；右侧是帛而非竟，读 jǐn。 |
| 景 | 近音 | 读 jǐng，声调不同；上方日、下方京。 |
| 静 | 同音 | 同读 jìng；左右为青和争。 |
| 惊 | 近音 | 读 jīng，声调不同；左侧忄，右侧京。 |

### 藏

默认 6 字：**藏、葬、茂、苍、仓、舱**。完整 9 字：**藏、葬、茂、蔽、苍、仓、舱、脏、臧**。

| 候选字 | 类型 | 辨认差异 / 选取理由 |
|---|---|---|
| 藏 | 正确答案 | 本课读 cáng；草字头下保留臣与外侧斜钩等字块。 |
| 葬 | 形似；近音 | 同有草字头和较密的上下结构，下方字块不同；读 zàng，与本课 cáng 不是同音。 |
| 茂 | 形似 | 同有草字头和下方斜钩，但没有藏里面的臣。 |
| 蔽 | 部分形似 | 同有草字头，下方笔画较密；下部为敝而非臧。 |
| 苍 | 近音 | 读 cāng，声调不同；同有草字头，但下面是仓。 |
| 仓 | 近音 | 读 cāng，声调不同；没有草字头，整体笔画少。 |
| 舱 | 近音 | 读 cāng，声调不同；左侧舟，右侧仓。 |
| 脏 | 近音 | 按“脏东西”读 zāng，与 cáng 声母、声调不同；左侧为月，不作为强形似字。 |
| 臧（进阶） | 强形似 | 读 zāng；与藏的下部相同，但没有草字头。 |

### 警

默认 6 字：**警、敬、誓、誉、景、井**。完整 9 字：**警、敬、誓、誉、惊、景、井、静、擎**。

| 候选字 | 类型 | 辨认差异 / 选取理由 |
|---|---|---|
| 警 | 正确答案 | 上方敬，下方言。 |
| 敬 | 形似；近音 | 保留警的上半部分，缺少下方言；读 jìng，声调不同。 |
| 誓 | 形似 | 下方同为言，上方是折而非敬。 |
| 誉 | 形似 | 下方同为言，上方是兴而非敬。 |
| 惊 | 近音 | 读 jīng，声调不同；左右结构，右边是京。 |
| 景 | 同音 | 同读 jǐng；上日下京，缺少警下方的言。 |
| 井 | 同音 | 同读 jǐng；笔画少，用于排除只凭读音选字。 |
| 静 | 近音 | 读 jìng，声调不同；左右为青和争。 |
| 擎（进阶） | 强形似 | 上方同为敬，下方是手而非言；读 qíng。 |

### 移动端呈现与反馈

- 默认 6 字用三列两行，9 字用三列三行；字卡至少 80 × 88px，间距 8—12px，允许页面纵向滚动，底部按钮不遮住最后一行。
- 所有字卡使用相同字体、字号和颜色，不显示拼音、部件颜色或类型标签；上述分类只供内容设计和陪伴者查看。儿童不必会读干扰字。
- 每轮开始随机排列，确保正确答案只出现一次；答错后保持本轮位置，避免孩子重新找卡片。下一轮重新排列。
- 点错时给一个具体的观察提示，例如“看看左边，是金字旁吗？”；允许再选或重看结构，不打叉、不扣分。使用提示后完成要记录为“在提示下认出”，不等同于独立认出。
- 嬴、羸、臧、擎较少见，只在进阶 9 字模式出现，不作为本轮新增学习目标。赢的常用干扰字与原字形似程度较弱，进阶时再比较下方中间的贝、女、羊。
- 这些形似等级与难度是设计假设，需通过儿童试用调整；一轮选对不能证明长期掌握。

## Agent 的作用

模型根据所选 lessonId、当前 componentId、已核对结构与记忆线索改写一句短讲解；默认一句约 6—12 字，必要时放宽到 18 字。可以换一种说法或回答当前字块的位置问题。模型不能生成或修改字形、部件、拼音、笔画索引或答案。接口无凭据、超时或校验失败时使用这份固定故事；来源在陪伴者设置中说明，不把本地回答伪装为实时模型。

## 后续实现需要调整

- 把单个 lesson.json 改为按单字选择课程的注册表；结构组件、插画、音频、故事、拼回、辨认都随课程切换。
- 状态流不再固定 focus<4 和五个 ID，按当前课程的 components.length 处理；辨认选项按课程提供。
- 把 start/end 连续索引升级为 strokeIndices，渲染、点击和归位统一读取同一份笔画映射。
- 结构位置来自每字配置，不能套用赢的上、中、下三层 CSS。
- 学习存档记录 lessonId；切字时取消旧朗读、旧模型请求和旧计时。最近学习的字支持全部四课。
- 增加三字普通话名称、位置、短故事和读音音频。

## 已做核对与待验证

现有 SVG：镜 16 笔、藏 17 笔、警 19 笔。JSON 的各组索引经自动检查：覆盖全部原始笔画，没有重复、遗漏或越界。形状联想和故事尚未经过儿童试用；尤其“藏”的小门／宝盒／围边方案，需要观察是否帮助认形，避免把联想记成真实字义。
