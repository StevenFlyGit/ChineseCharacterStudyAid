# 《心音字灵》移动端 PRD 与交互原型方案

## 1. 产品定位与交付

**一句话定位：为确诊读写障碍儿童提供由家长或教师陪伴的汉字学习辅助工具，把复杂字拆成可理解的小块，再通过故事、操作和辨认帮助孩子建立记忆。**

首版面向确诊读写障碍、在汉字字形记忆或辨认上遇到困难的儿童，由家长或教师陪伴使用；依据孩子当前识字水平选择教学内容，不设置固定年龄门槛。“赢”作为首版路演样例，不要求所有孩子都从该字开始。产品名暂用《心音字灵》，不承诺治疗或替代专业教学。

本次交付：

- 一份完整中文 PRD，覆盖背景目标、用户与场景、范围、指标、角色、学习闭环、移动页面、交互说明、数据与接口、非功能需求、实施与验证、风险及术语。
- 一个自包含的单文件 HTML，包含“PRD 说明／移动学习原型／路演模式”三个入口，可直接本地打开。
- PRD 附录提供一分钟分镜、固定故事数据、AI Prompt、三分钟路演讲稿和半天开发任务表。

新方案单独保存，保留现有《字有引力》方案与代码。此次交付侧重需求与原型，不直接改造现有游戏。

## 2. 核心产品设计

### 学习闭环与页面

首版只围绕 **“赢”**完成一条闭环，正常学习由孩子控制节奏，约 3—5 分钟；路演模式提供约一分钟的紧凑路径。

| 页面 | 内容与操作 | 反馈 |
|---|---|---|
| 开始学习 | 陪伴者进入，显示清晰的“赢”、读音和“我们一起看看这个字” | 孩子点击“帮我拆开” |
| 看清结构 | 保留整字轮廓，依次突出亡、口、月、贝、凡 | 每次只关注一块，可重听、前进 |
| 听短故事 | 当前部分与对应简笔画同时出现 | 图像退回字形，保持故事与结构的联系 |
| 亲手拼回 | 点选一块，再点对应位置；拖拽作为可选操作 | 正确归位；放错时保留选择并提示位置 |
| 再认一次 | 隐去颜色、故事与轮廓提示，从“赢、营、迎”中选择刚才学习的字 | 展示本次辨认结果，可求助、再学或结束 |

“赢”的日常释义单独呈现：**“赢，yíng，在比赛中获胜。”** 故事负责记忆联想，不承担字源或构形解释。

固定故事采用用户选定的简短版本：

> 亡像小帽，口来呼唤，月亮照路，贝壳作伴。  
> 平凡的我，一步一步向前。

结尾反馈：

> 你找到方法了。我们把复杂的字，一块一块看清楚。

### 一分钟高光

| 时间 | 画面与动作 |
|---|---|
| 0—7 秒 | 展示稳定的“赢”。旁白：“这个字很复杂，不知道从哪里开始？我们一块一块看。” |
| 7—12 秒 | 点击“帮我拆开”，五块沿字形位置展开，整字轮廓仍可见 |
| 12—32 秒 | 五句故事依次播放，每块约四秒；当前块突出，其余保持可辨 |
| 32—45 秒 | 演示者依次点选、归位五块，观察结构逐步完整 |
| 45—49 秒 | 五块组成标准“赢”，短暂柔和光点收拢，并读出字音 |
| 49—57 秒 | 切换为无颜色提示的辨认题，由演示者实际作答 |
| 57—60 秒 | 展示本次操作记录及“你找到方法了” |

路演节奏允许人工暂停；操作超时不自动替孩子答题。自动播放只能用于预览动画，不能生成学习成绩。

### 移动交互

- 手机竖屏优先，验收宽度为 360、390、430px；桌面展示居中的手机学习界面。
- 教学区居中，底部固定主要按钮并适配安全区；五个字块分两行排列。
- 主要按钮和字块至少 56px，正文至少 18px；每屏只提供一个主要任务。
- 颜色同时配合轮廓、位置与文字提示，避免仅靠颜色判断。
- 全程可暂停、重听、静音和退出；减少动态效果时使用直接归位。
- 错误不打红叉、不扣分，但明确指出需要调整的位置，例如：“这一块在下面，我们一起放回去。”
- 儿童界面保持稳定字形，不使用扭曲、模糊、持续漂移和强烈纸屑效果。

## 3. MVP 范围、技术与接口

### 优先级

**P0：半天必须完成**

“赢”的结构展示、固定故事、点选拼回、柔和重组、无提示辨认、本次记录、移动适配、路演控制，以及本地／API 模式切换。

**P1：闭环稳定后接入**

真实 AI 短故事与提示、简单字教学样例、短延迟复习、轻量陪伴者记录。

**后续蓝图**

笔画辅助、词语与成语、单句古诗、教师内容审阅与课程配置。采用“笔画—字—词—句”的渐进结构，不把四层内容同时塞进首版。

首版不加入眼动、摄像头、情绪识别、自由手写评分、登录、多角色管理或开放式聊天。停顿只能触发“需要提示吗”，不能判定迷茫或诊断能力。

### 实现方式

沿用现有 **React + TypeScript + Vite**；真实调用复用 Express。HTML 原型使用内联 CSS、JavaScript、SVG，无 CDN 或远程素材依赖。

“赢”使用项目已有的 17 笔 SVG 数据，按五组路径拆分：

- 亡：第 1—3 笔；
- 口：第 4—6 笔；
- 月：第 7—10 笔；
- 贝：第 11—14 笔；
- 凡：第 15—17 笔。

重组时恢复原 SVG 坐标，确保最终字形准确；不通过五个独立字体字符重叠实现。组别、字形和联想标注在交付前人工核对。

### 双模式与 AI 边界

- 默认 `mock`：全部读取本地故事，不调用模型或状态查询接口。
- 电脑通过 `Ctrl + H` 切换，拦截浏览器默认动作；移动端在陪伴者设置中切换。
- 陪伴者设置和路演控制明确显示“本地脚本／真实 API／本地回退”。
- 切换模式会取消旧请求，并从当前稳定阶段继续；旧响应不能覆盖新状态。
- 真实请求超过三秒、结构无效或服务不可用时使用固定故事，并标明回退。
- 一秒响应是优化目标，不作为演示保证。没有服务或凭据时明确显示不可用。

拟新增 `POST /api/story`：

| 输入 | 输出 |
|---|---|
| 固定 `lessonId`、故事主题、讲解长度、人工核对内容版本 | 一句开场、五句短联想、一句结束语、内容来源 |

AI 仅调整短讲解与提示，不能修改字形、部件顺序、读音、释义或返回执行代码。输出逐句校验长度、结构和固定顺序；不合格时整段回退。密钥只由 Express 读取。

HTML 直接打开时使用本地模式；真实 API 需在同源 HTTP 服务中运行。原型不会把模拟响应显示为真实调用。

状态机采用：

`开始 → 结构展示 → 故事 → 拼回 → 辨认 → 本次结果`

本地仅保存设置、稳定阶段、内容版本、尝试与求助次数；不采集诊断证明、姓名、影像或健康档案。“拼回完成”和“无提示辨认”分开记录。

## 4. 验收与半天实施安排

### 验收标准

- 五组路径拼回后与标准“赢”完全一致，故事明确属于记忆联想。
- 点选和触摸均可完成；错误位置、重复点击、暂停、返回和重播不会跳阶段。
- 辨认结果来自真实操作；路演预览与学习记录分离。
- 本地模式无应用 API 请求；真实模式覆盖成功、超时、无效响应及切换取消。
- 静音、无中文语音、减少动态效果、存储不可用时仍可完成闭环。
- 三种手机宽度无横向溢出，底部操作无遮挡；单文件原型无控制台错误。
- 排练至少三次，完整路演不超过三分钟，一分钟高光可重复演示。

固定音频优先预置；浏览器朗读作为补充，无法播放时保留字幕和手动前进。

### 六小时预算

| 时间 | 工作 |
|---|---|
| 0—0.5 小时 | 锁定文案、页面和教学标注 |
| 0.5—2.5 小时 | 完成手机布局、SVG 拆分、故事与重组 |
| 2.5—4 小时 | 完成点选拼回、辨认、结果与双模式控制 |
| 4—4.5 小时 | 接入真实 API 适配；不可用时保留明确状态 |
| 4.5—5.5 小时 | 验证触摸、音频、异常和原型联动 |
| 5.5—6 小时 | 三分钟排练、录制备用演示 |

三分钟路演分配：问题与场景 30 秒，高光操作 60 秒，产品闭环和 AI 分工 45 秒，验证计划与后续方向 45 秒。

## 5. 证据、指标与默认假设

读写障碍不能统一描述为看到漂移或破碎的文字，产品采用用户确认的稳定字形与逐块聚焦。[国际读写障碍协会说明](https://mi.dyslexiaida.org/about-dyslexia/)

中文形态意识干预有研究依据，但一项随机分组研究并未发现部首意识的显著改善，不能据此宣称本产品的故事拆字有效。[相关研究](https://pubmed.ncbi.nlm.nih.gov/41032151/)

因此，PRD 区分三类指标：

- **交付指标**：半天完成闭环、手机可操作、三分钟可演示。
- **可用性指标**：孩子能否找到下一步、理解操作、接受提示并继续尝试。
- **学习观察**：无提示辨认、求助次数和后续保留表现；一次成功不等同于掌握或疗效。

目前没有专业评审或家庭试用渠道。首版作为设计原型和黑客松演示，后续先请专业人员审阅内容，再开展有陪伴的儿童试用。验证时观察结构聚焦是否降低操作困难、故事是否反而增加记忆负担，以及撤去提示后的辨认与复习表现。

默认使用普通话、简体汉字、陪伴学习；产品名暂定，后续试用按识字水平匹配内容。获奖表现不作为可保证结果，路演重点是让观众看清问题、操作、反馈和仍待验证的价值。
